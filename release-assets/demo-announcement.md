# Tradia Agentic Trading OS v0.1.0 — Launch

Agentic trading intelligence for trade proposals, risk checks, journals, performance reports and public accountability updates.

## What's Included

- **CLI** — Full command-line interface. Plan, risk-check, journal and report trades from your terminal.
- **SDK** — TypeScript SDK for Node.js. `@talocode/tradia` on npm.
- **API Server** — REST API with 14 endpoints for integration.
- **MCP Tools** — Model Context Protocol tools for AI agent integration.
- **Risk Engine** — Position sizing, risk-reward, drawdown, revenge trading detection.
- **Journal System** — Structured journal entries with discipline scores and lessons.
- **Performance Analytics** — Win rate, profit factor, expectancy, R-multiples.
- **Backtest Simulation** — Equity curves, win rates, drawdown analysis.
- **Public Accountability** — Generate public updates explaining trades and performance.

## Safety First

Tradia v0.1 is agentic trading intelligence, not live execution.

- No broker integration
- No financial advice
- No guaranteed profits
- Human review required on every output

## Install

```bash
npm install -g @talocode/tradia
```

## Quick Start

```bash
tradia propose --symbol XAUUSD --market forex --strategy liquidity_sweep --balance 500 --risk 0.5
```
